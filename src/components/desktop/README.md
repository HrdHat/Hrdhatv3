# Desktop Components

This directory contains React components specifically designed for desktop/web browser environments.

## Purpose

- Components optimized for larger screens and mouse/keyboard interactions
- Desktop-specific UI patterns and layouts
- Components that leverage desktop browser capabilities

## Current Components

- `ImageUploaderWithCamera.tsx` - Desktop image upload component with camera integration

## Guidelines

- Components here should be responsive but optimized for desktop viewports (≥1024px)
- Use desktop-appropriate interaction patterns (hover states, right-click menus, etc.)
- Leverage desktop browser APIs when beneficial
- Consider keyboard navigation and accessibility

## Usage

These components are typically used in the desktop layout shell or conditionally rendered based on screen size detection.
