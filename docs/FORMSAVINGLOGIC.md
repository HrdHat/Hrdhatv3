Saving works by sending each module’s form data—like General Info, PPE, or Checklist—as a structured payload to a centralized save function (saveFormModuleData). This function uses the module's key to map to the correct Supabase table, validates the data, and performs an upsert with the form ID as the foreign key. On the frontend, changes are auto-saved using a debounced hook with retry and offline support, ensuring smooth, background persistence without user interruption.
